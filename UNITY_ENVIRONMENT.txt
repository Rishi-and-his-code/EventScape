# =============================================================
# Virtual Auditorium - Interactive 3D Auditorium Decoration &
# Event Layout Planner
# Project Requirements / Environment Setup
# =============================================================
#
# NOTE: This is a Unity (C#) project, not a Python project.
# Unity does not use pip / requirements.txt for dependency
# management - Unity packages are tracked in
# Packages/manifest.json via the Unity Package Manager (UPM),
# and that file should already be committed to this repo.
# This file exists purely as human-readable documentation, so
# anyone cloning the repo knows exactly what to install before
# opening the project.

# ---- Core Engine ----
Unity Hub (latest)
Unity Editor 2022.3 LTS or newer          # LTS recommended for stability
.NET / Mono                               # bundled automatically with Unity, no separate install needed

# ---- Unity Packages (installed via Window > Package Manager;
#      already declared in Packages/manifest.json) ----
com.unity.inputsystem                     # WASD + mouse navigation, orbit controls
com.unity.cinemachine                     # switching between first-person and orbit camera
com.unity.render-pipelines.universal      # URP - lighting, materials, real-time rendering
com.unity.textmeshpro                     # UI text for the side panel / object catalog
com.unity.ugui                            # Canvas-based UI system for buttons/panels

# ---- 3D Modeling ----
Blender 3.6 or newer                      # modeling the auditorium shell + furniture, export as .fbx

# ---- Asset Sources (no install needed, referenced for asset prep) ----
# Kenney.nl free low-poly asset packs
# Poly Pizza (free low-poly models)

# ---- Version Control ----
Git
Git LFS                                   # required - .fbx/.blend/texture files are binary and can get large

# ---- IDE ----
Visual Studio 2022 Community (with Game Development with Unity workload)
# or: VS Code + C# Dev Kit extension + Unity extension

# ---- Recommended OS ----
Windows 10/11 or macOS                    # Unity Editor supported desktop platforms

# ---- Optional (only if the team adds a save/load layout feature) ----
Newtonsoft.Json for Unity (via UPM: com.unity.nuget.newtonsoft-json)   # JSON serialization for saved layouts
