# Unity scaffold notes (scaffold-only)

This repo currently contains the professor-required **Python baseline** plus a **Unity-ready folder + C# stubs**.

## What you can do next (in Unity Editor)

1. Create/open a Unity **2022.3 LTS** project.
2. Copy or import the stubs from:
   - `Unity/EventScape/Assets/Scripts/**`
3. Ensure packages are installed (UPM):
   - Input System, Cinemachine, URP, UGUI, TextMeshPro
4. Create one scene (e.g. `Scenes/MainAuditorium`) and wire:
   - `CameraModeSwitcher` (hotkey Tab)
   - `PlacementSystem` + `GhostPreview`
   - `ObjectCatalogPanel`
